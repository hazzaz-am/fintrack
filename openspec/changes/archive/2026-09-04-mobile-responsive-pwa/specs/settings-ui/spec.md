## ADDED Requirements

### Requirement: Settings screen remains usable at phone widths
The Settings screen's Profile and Categories sections SHALL remain fully usable at phone widths without horizontal scrolling or overlapping controls.

#### Scenario: Settings screen viewed at 375px width
- **WHEN** the Settings screen is loaded at a 375px viewport width
- **THEN** the Profile and Categories sections stack in a single column with all form fields and category management controls fully reachable without horizontal scrolling
